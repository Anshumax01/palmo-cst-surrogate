# Airfoil Design

Developed at the **CEREAL (Computational and Experimental Rotorcraft Engineering 
and Aerodynamics) Lab, Georgia Institute of Technology**.

## Goal

Given target aerodynamic objectives (e.g. minimize drag, maximize lift), use the 
surrogate model to output the optimal airfoil shape and geometry.
